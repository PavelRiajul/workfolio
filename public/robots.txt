# AI crawlers are welcome, and saying so explicitly matters. The wildcard above
# already permits them, but several of these agents are blocked by default in
# hosting presets and boilerplate robots files — an unstated allow is one
# copy-paste away from becoming a silent block.
#
# They share one rule block on purpose. A named user-agent group replaces the
# `*` group for that agent rather than adding to it, so each of these would
# otherwise lose the /admin disallow above and start crawling the Studio.
#

# Claude-SearchBot) fetch a page to answer a live question. The rest also build

# effect on ranking in Google Search.
